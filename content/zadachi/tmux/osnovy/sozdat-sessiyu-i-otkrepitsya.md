# Задача: Создать сессию, отцепиться и вернуться

Создайте именованную tmux-сессию `practice`, разделите её единственное окно на 2 панели, отцепитесь от сессии, не убив её, убедитесь из обычного шелла, что сессия всё ещё существует, и прицепитесь к ней обратно.

<details>
<summary>Решение</summary>

```bash
tmux new -s practice
```

Внутри сессии разделить панель (дефолтный бинд, без своего конфига):

```
prefix %
```

Отцепиться, не завершая сессию:

```
prefix d
```

Из обычного шелла (сессия продолжает жить в фоне):

```bash
tmux ls
```

должна показать `practice` в списке. Вернуться:

```bash
tmux attach -t practice
```

обе панели окажутся на месте — detach не завершает процессы внутри сессии, только отсоединяет от неё терминал.

</details>
