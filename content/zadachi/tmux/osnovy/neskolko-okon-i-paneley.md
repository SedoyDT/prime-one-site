# Задача: Несколько именованных окон и панелей

В одной сессии создайте 3 окна с осмысленными именами (`editor`, `server`, `logs` — не дефолтные номера), в окне `editor` сделайте 2 панели, и переключитесь между всеми тремя окнами и панелями, не трогая мышь. Задача рассчитана на конфиг oh-my-tmux — [[tmux-i-oh-my-tmux|см. туториал про установку]].

<details>
<summary>Решение</summary>

```bash
tmux new -s multi
```

Переименовать первое окно и создать ещё два:

```
prefix ,
editor<Enter>

prefix c
prefix ,
server<Enter>

prefix c
prefix ,
logs<Enter>
```

Вернуться в окно `editor` (переключение по номеру или последнему активному) и разбить его на 2 панели биндами oh-my-tmux:

```
prefix _
```

(`_` — вертикальный сплит, новая панель сбоку, в отличие от дефолтного `"`). Переключение между панелями внутри окна — vim-стиль:

```
prefix h / prefix l
```

Переключение между окнами:

```
prefix C-h / prefix C-l   (предыдущее / следующее)
prefix Tab                 (последнее активное окно)
```

Ни разу не потребовалась мышь и не потребовались числовые номера окон — только имена и относительная навигация.

</details>
