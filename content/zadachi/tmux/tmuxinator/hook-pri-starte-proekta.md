# Задача: Хук при старте проекта

Добавьте в существующий tmuxinator-проект хук, который печатает сообщение **до** того, как поднимутся окна проекта.

<details>
<summary>Решение</summary>

```yaml
name: demo
root: ~/

on_project_start: echo "Запускаю проект demo..."

windows:
  - editor:
      layout: main-vertical
```

`on_project_start` выполняется на каждый запуск проекта (в отличие от `on_project_first_start`, который срабатывает только один раз — при самом первом старте). Именно поэтому сообщение печатается до появления окон — хук идёт раньше поднятия `windows`.

</details>
