# Задача: Переменные и типы данных

Напишите переменные для хранения: цены товара (число), названия товара (строка), флага "товар в наличии" (булево). Выведите все три в консоль через `console.log`.

<details>
<summary>Решение</summary>

```js
const price = 199.99;
const title = "Кофемашина";
let inStock = true;

console.log(price, title, inStock);
```

</details>
