# Задача: Образы и контейнеры: жизненный цикл

Запустите контейнер `nginx` без `-d` и без `--rm`, дождитесь, пока он выведет пару строк лога, затем в **другом** терминале (или после `Ctrl+C`) убедитесь командой, что контейнер существует, но остановлен, и удалите его.

<details>
<summary>Решение</summary>

```bash
# Терминал 1
docker run --name test-nginx nginx
# Ctrl+C после первых строк лога — процесс останавливается

# Убедиться, что контейнер остановлен, но не исчез
docker ps -a
# STATUS будет "Exited (0)" или похожим

# Удалить
docker rm test-nginx
```
`Ctrl+C` посылает сигнал главному процессу контейнера, тот завершается — контейнер переходит в `Exited`, но остаётся в списке `docker ps -a`, пока его явно не удалят.

</details>
