# Задача: Свой плагин и отключение дефолтного

Создайте `lua/plugins/my-plugin.lua`, который: (а) отключает один встроенный в LazyVim плагин через `enabled = false`, и (б) в том же файле добавляет спеку нового плагина, лениво загружаемого только по команде (`cmd`).

<details>
<summary>Решение</summary>

```lua
return {
  -- (а) отключить встроенный плагин, не удаляя его
  { "встроенный/плагин", enabled = false },

  -- (б) новый плагин, загружается только при первом вызове :MyCommand
  {
    "автор/новый-плагин",
    cmd = "MyCommand",
    opts = {},
  },
}
```

Файл возвращает **одну** таблицу с двумя спеками — lazy.nvim подхватывает `lua/plugins/*.lua` автоматически, отдельный `require` не нужен. `enabled = false` в первой спеке гасит плагин, оставляя его установленным (в отличие от полного удаления из конфига). Вторая спека не загрузится при старте Neovim вовсе — только в момент, когда действительно вызвана команда `:MyCommand`, что и проверяется через `:Lazy` (плагин будет висеть в списке как «not loaded», пока команда не вызвана хотя бы раз).

</details>
