# Задача: Движения по словам и удаление до конца строки

Дана строка `первое второе третье четвёртое пятое`. Встаньте курсором на первую букву строки и, используя только движения по словам (без стрелок и без подсчёта символов), доберитесь до начала третьего слова, затем одной командой удалите всё от этой позиции до конца строки.

<details>
<summary>Решение</summary>

```
ww
d$
```

`w` дважды переносит курсор на начало второго, затем третьего слова («третье»). `d$` — оператор `d` с движением `$` (конец строки) — удаляет всё от текущей позиции курсора включительно до конца строки одной операцией. Результат: `первое второе `. Эквивалент `d$` для этой ситуации — `D`.

</details>
