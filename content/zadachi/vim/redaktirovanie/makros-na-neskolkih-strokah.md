# Задача: Макрос на нескольких строках

Файл содержит 5 строк, каждая начинается с одного слова без кавычек (например `яблоко`, `груша`, ...). Оберните первое слово каждой строки в кавычки (`"яблоко"`), используя один записанный макрос.

<details>
<summary>Решение</summary>

Встать курсором на первую строку (в начало строки — `0` или `^`), затем:

```
qa0i"<Esc>ea"<Esc>j0q
4@a
```

Разбор: `qa` — начать запись в регистр `a`. `0` — в начало строки. `i"` — вставить кавычку перед первым символом, `Esc` — выйти в Normal. `e` — на конец текущего слова. `a"` — добавить кавычку сразу после него, `Esc`. `j0` — перейти на следующую строку, в её начало. `q` — остановить запись. Дальше `4@a` воспроизводит записанное ещё 4 раза — по разу на каждую из оставшихся строк.

**Важно:** макрос сработает одинаково только если все 5 строк устроены одинаково — одно слово в начале, без лишних пробелов. Если хотя бы одна строка структурно другая (два слова, лишний пробел), движения `e`/`j0` внутри макроса «доедут не туда» именно на ней — это и есть та самая ловушка хрупкости макросов из основного туториала.

</details>
