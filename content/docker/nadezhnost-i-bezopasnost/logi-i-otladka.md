# Задача: Логи и отладка: logs, exec, inspect, stats

Контейнер `myapp` упал сразу после старта. Опишите последовательность из трёх команд, которая: (1) покажет последние 20 строк его лога, (2) покажет код выхода, (3) покажет, какая команда вообще была задана как точка входа контейнера.

<details>
<summary>Решение</summary>

```bash
docker logs --tail 20 myapp

docker inspect --format='{{.State.ExitCode}}' myapp

docker inspect --format='{{.Config.Cmd}}' myapp
```
Такая связка обычно быстро выявляет причину: лог покажет текст ошибки, код выхода — тип сбоя (0 — штатно, ненулевой — ошибка приложения, 137 — OOM-kill), а `Config.Cmd` подтвердит, что контейнер вообще пытался запустить то, что задумывалось.

</details>
