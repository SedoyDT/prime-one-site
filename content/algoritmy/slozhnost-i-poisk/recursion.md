# Задача: Рекурсия: введение

Напишите рекурсивную функцию `fibonacci(n)`, возвращающую n-е число Фибоначчи (0, 1, 1, 2, 3, 5, ...).

<details>
<summary>Решение</summary>

```js
function fibonacci(n) {
  if (n <= 1) return n;
  return fibonacci(n - 1) + fibonacci(n - 2);
}

console.log(fibonacci(7)); // 13
```
Замечание: это решение экспоненциальное — O(2^n), потому что одни и те же подзадачи считаются заново. Это станет отправной точкой для урока 080 (динамическое программирование).

</details>
