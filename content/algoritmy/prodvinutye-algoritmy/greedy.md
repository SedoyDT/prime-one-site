# Задача: Жадные алгоритмы

Решите задачу "размен монет жадно" для номиналов [1, 5, 10, 25] (для этих номиналов жадный подход даёт оптимум) и объясните, почему здесь жадность работает, в отличие от [1, 3, 4].

<details>
<summary>Решение</summary>

```js
function greedyCoins(coins, amount) {
  const sorted = [...coins].sort((a, b) => b - a);
  let count = 0;
  for (const coin of sorted) {
    count += Math.floor(amount / coin);
    amount %= coin;
  }
  return amount === 0 ? count : -1;
}

console.log(greedyCoins([1, 5, 10, 25], 63)); // 6
```
Причина: номиналы [1,5,10,25] образуют "каноническую" систему, где каждый следующий номинал кратен предыдущему с достаточным запасом — жадный выбор никогда не блокирует оптимум. У [1,3,4] это не так.

</details>
