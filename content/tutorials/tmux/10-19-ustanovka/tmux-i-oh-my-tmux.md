# Установка tmux и конфиг oh-my-tmux

Уровень сложности: ~15/100.

**Предполагается:** базовая модель сессий/окон/панелей — [[sessii-okna-paneli|tmux: сессии, окна и панели]]. Дальше — [[ustanovka-i-proekty|tmuxinator: описываем проект в YAML]].

## Установка самого tmux

```bash
sudo apt install tmux    # Debian/Linux Mint
brew install tmux        # macOS / Homebrew на Linux
```

## Зачем готовый конфиг вместо голых дефолтов

Дефолтные биндинги из предыдущего туториала рабочие, но неэргономичные — `prefix %`/`prefix "` для сплитов не мнемоничны, переключение панелей не в стиле `hjkl`, а тема статус-бара голая. **oh-my-tmux** ([gpakosz/.tmux](https://github.com/gpakosz/.tmux)) — готовый конфиг с разумными биндами и темой, при этом кастомизация вынесена в отдельный файл, не трогающий основной.

```bash
git clone https://github.com/gpakosz/.tmux ~/.tmux
ln -s ~/.tmux/.tmux.conf ~/.tmux.conf
cp ~/.tmux/.tmux.conf.local ~/.tmux.conf.local
```

Идея та же, что у `lua/plugins/` в LazyVim: `.tmux.conf` — ядро, которое можно свободно обновлять (`git pull` в `~/.tmux`), `.tmux.conf.local` — своя кастомизация (тема, дополнительные бинды), которая ядро не трогает. На этой машине `.tmux.conf`/`.tmux.conf.local` — не просто файлы, а симлинки на копии внутри `frolov-center` — конфиг переживает переустановку системы и правится в одном месте для всех машин.

## Prefix остаётся тем же, плюс второй

oh-my-tmux **не** меняет prefix — по умолчанию всё так же `Ctrl-b`. Дополнительно добавлен `prefix2 Ctrl-a` (совместимость с привычками GNU Screen) — обе комбинации работают как prefix одновременно.

## Реальные биндинги этого конфига

Разделение панелей — **другие** клавиши, чем дефолтные `%`/`"` из предыдущего туториала:

- `prefix -` — `split-window -v` (новая панель снизу).
- `prefix _` — `split-window -h` (новая панель сбоку).

Навигация — в стиле Vim, `hjkl` вместо стрелок:

- `prefix h/j/k/l` — переход между панелями (левая/нижняя/верхняя/правая), сочетание повторяемое — можно держать, не нажимая prefix заново.
- `prefix H/J/K/L` — изменение размера текущей панели на 2 ячейки в соответствующую сторону, тоже повторяемое.

Окна и сессии:

- `prefix C-h` / `prefix C-l` — предыдущее / следующее окно.
- `prefix Tab` — переключиться на последнее активное окно.
- `prefix BTab` — переключиться на последнюю активную сессию.
- `prefix C-c` — новая сессия (с запросом имени).
- `prefix C-f` — найти сессию по имени и переключиться на неё.

Служебное:

- `prefix r` — перечитать конфиг (`source`) и показать подтверждение.
- `prefix e` — открыть `.tmux.conf.local` в `$EDITOR` для правки, при сохранении конфиг перечитывается автоматически.

Copy-mode (vi-style):

- `prefix Enter` — войти в copy-mode.
- Внутри: `v` — начать выделение, `C-v` — переключить в прямоугольное выделение, `y` — скопировать выделенное и выйти, `Escape` — отменить, `H`/`L` — начало/конец строки.

Управление плагинами (TPM):

- `prefix I` — установить плагины.
- `prefix u` — обновить плагины.
- `prefix Alt+u` — удалить неиспользуемые плагины.

Один важный дефолт этого конфига: `tmux_conf_new_pane_retain_current_path=true` — новая панель открывается в той же директории, что и текущая, а не в `$HOME`. Мелочь, но именно она избавляет от постоянных `cd` после каждого сплита.

## Проверка себя

Пересоберите пример из предыдущего туториала (сессия, окно, 2 панели), но уже новыми биндами: `prefix -`/`prefix _` для сплитов вместо `%`/`"`, `prefix h/j/k/l` для перемещения между панелями. Проверьте `prefix r` — измените в `.tmux.conf.local` любую мелочь (например цвет) и перечитайте конфиг без перезапуска tmux.
