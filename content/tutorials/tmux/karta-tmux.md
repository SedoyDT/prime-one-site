# tmux и tmuxinator: от сессий к автоматизации проектов

Три туториала по возрастанию сложности — от базовой модели «сессия / окно / панель» на дефолтных биндах (уровень ~5) до описания целого проектного окружения в YAML (уровень ~25). Порядок осмысленный: сначала дефолты tmux без всякого конфига, чтобы понимать, что вообще происходит, потом удобный конфиг (oh-my-tmux) поверх них, и только потом — автоматизация через tmuxinator поверх уже понятного tmux.

Сценарии применения на практике — [[scenarii-primeneniya-tmux-tmuxinator|tmux и tmuxinator: сценарии использования]]. Короткие задачи с решением под спойлером — [[tmux|tmux и tmuxinator: задачи для практики]].

## 00–09 · Основы

- [[sessii-okna-paneli|tmux: сессии, окна и панели — базовая модель]] — `tmux new -s`, `attach`, дефолтный prefix `Ctrl-b`, окна и панели без стороннего конфига.

## 10–19 · Установка и конфиг

- [[tmux-i-oh-my-tmux|Установка tmux и конфиг oh-my-tmux]] — oh-my-tmux, `.tmux.conf`/`.tmux.conf.local`, реальные биндинги (сплиты, vim-навигация панелями, copy-mode, TPM).

## 20–29 · tmuxinator

- [[ustanovka-i-proekty|tmuxinator: описываем окружение проекта в YAML]] — `gem install tmuxinator`, структура yml-конфига, project hooks, весь проект одной командой.
