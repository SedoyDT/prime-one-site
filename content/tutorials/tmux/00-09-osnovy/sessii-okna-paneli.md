# tmux: сессии, окна и панели — базовая модель

Уровень сложности: ~5/100. Нужен установленный tmux (`tmux -V` для проверки) — здесь используются только его дефолтные, «из коробки» сочетания клавиш, без какого-либо своего конфига.

**Предполагается:** ничего. Дальше — [[tmux-i-oh-my-tmux|установка tmux и конфиг oh-my-tmux]].

## Зачем вообще мультиплексор терминала

tmux держит терминальные сессии живыми независимо от того, открыто ли окно терминала прямо сейчас. Работа внутри tmux-сессии продолжается, даже если закрыть терминал или отвалится SSH — сессию можно «отцепить» и позже «прицепиться» обратно, ничего не потеряв.

## Три уровня вложенности

- **Сессия** — самый внешний контейнер, обычно одна на проект/задачу.
- **Окно** (window) — как вкладка внутри сессии, у окна есть имя и номер.
- **Панель** (pane) — окно можно разделить на несколько панелей side-by-side.

## Команды из обычного шелла (без tmux)

```bash
tmux new -s имя      # создать именованную сессию
tmux ls               # список всех сессий
tmux attach -t имя    # прицепиться к сессии (короткая форма: tmux a -t имя)
```

## Дефолтный prefix: `Ctrl-b`

Почти все команды внутри tmux начинаются с **prefix** — по умолчанию `Ctrl-b`, отпустить, затем нажать вторую клавишу. Дальше везде `prefix X` означает именно эту последовательность.

- `prefix d` — отцепиться от сессии (detach), сессия продолжает жить в фоне.
- `prefix c` — новое окно.
- `prefix n` / `prefix p` — следующее / предыдущее окно.
- `prefix ,` — переименовать текущее окно.
- `prefix &` — закрыть текущее окно (с подтверждением).
- `prefix %` — разделить панель вертикально (новая панель справа).
- `prefix "` — разделить панель горизонтально (новая панель снизу).
- `prefix x` — закрыть текущую панель (с подтверждением).
- Переключение между панелями — стрелки после `prefix o`, либо напрямую `prefix` + стрелка.

## Проверка себя

Создайте сессию `tmux new -s test`, разделите окно на 2 панели (`prefix %`), создайте второе окно (`prefix c`) и дайте ему осмысленное имя (`prefix ,`), отцепитесь (`prefix d`), убедитесь через `tmux ls` из обычного шелла, что сессия всё ещё жива, и прицепитесь обратно (`tmux a -t test`).
