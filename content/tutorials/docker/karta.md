# Docker: от контейнеров до оркестрации

Десять туториалов, выстроенных по возрастанию сложности — от «что такое контейнер» (уровень ~5) до первого знакомства с оркестрацией (уровень ~95). Каждый туториал — законченная единица: у него есть свой список допущений («Предполагается»), свои воспроизводимые шаги и свой результат. Читать по порядку не обязательно, но материал специально устроен так, чтобы порядок был осмысленным — каждый следующий уровень использует один новый кусок логики поверх предыдущего.

Если после туториала хочется проверить себя короткими задачами с решением под спойлером — параллельный набор: [[docker|Docker: задачи для практики]].
