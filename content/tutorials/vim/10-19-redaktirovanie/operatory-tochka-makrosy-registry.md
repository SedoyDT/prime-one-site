# Редактирование: операторы, точка-повтор, макросы и регистры

Уровень сложности: ~20/100.

**Предполагается:** уверенное `hjkl`/`w`/`e`/`b` и понимание композиции «оператор + движение» — [[rezhimy-i-navigaciya|режимы и базовая навигация]]. Дальше — [[poisk-i-substitute|поиск и замена]].

## `x` против `dd`

- `x` — удаляет один символ под курсором.
- `dd` — удаляет всю текущую строку целиком, кладёт её в регистр — фактически «вырезать», а не просто стереть.

Частая путаница новичков: `x` кажется «универсальным удалением», хотя это самая мелкая единица. Для строки — всегда `dd`, не пять раз `x`.

## `cw` — атомарная замена слова

`cw` (change word) в одно действие удаляет слово и сразу переключает в Insert — в отличие от `dw` + `i` (две отдельные команды), это одна операция, которую потом можно повторить целиком.

## Точка-повтор: `.`

`.` повторяет последнее изменение. Если только что сделали `cw` и напечатали новое слово, `.` на другом слове повторит ровно это — удалить слово, напечатать то же самое. Это одна из самых быстрых операций в Vim для точечных правок в нескольких местах: `cw` один раз, `.` — везде похожем.

## Отмена: `u` и `Nu`

`u` отменяет **один** шаг. Если после `u` отменилось меньше, чем ожидали — это не баг, а норма: жмите `u` ещё раз или сразу `Nu` (например `5u`) для отмены нескольких шагов подряд.

## Макросы: `qa` … `q`, `@a`, `5@a`

Макрос — это запись последовательности нажатий в регистр:

```
qa   " начать запись в регистр a
... действия ...
q    " остановить запись
@a   " воспроизвести один раз
5@a  " воспроизвести 5 раз подряд
@@   " повторить последний воспроизведённый макрос
```

**Ловушка:** макрос, где движения завязаны на конкретное содержимое или длину строки, ломается при воспроизведении на структурно другой строке. Если макрос сработал на первой строке, но начал сбоить на второй — почти всегда причина именно в этом: движения типа `w`, `$`, `f<символ>` доехали не туда, потому что строка устроена иначе. Лекарство — либо делать движения более «понятийными» (искать по паттерну вместо счёта символов), либо заменить макрос на `:%s` с regex там, где преобразование это позволяет.

## Регистры: куда девается удалённое

Безымянный регистр `"` хранит последний yank/delete — `p` вставляет именно его. Если нужно скопировать один кусок текста, потом удалить другой, не потеряв первый — копируйте в **именованный** регистр явно:

```
"ayy   " скопировать строку в регистр a
dd     " удалить другую строку — перезапишет только безымянный регистр
"ap    " вставить из регистра a — по-прежнему тот, первый, кусок
```

## Проверка себя

Возьмите файл с 5 похожими строками (например список из пяти `TODO: сделать X`). Однократно исправьте первую строку через `cw`, затем повторите правку на всех остальных через `.`. Затем сотрите строку 3 через `dd`, убедитесь что `p` возвращает именно её.
