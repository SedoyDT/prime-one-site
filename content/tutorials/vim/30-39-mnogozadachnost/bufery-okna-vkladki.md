# Буферы, окна и вкладки: многозадачность внутри Vim

Уровень сложности: ~30/100.

**Предполагается:** поиск и замена — [[poisk-i-substitute|поиск и `:%s`]]. Дальше — переход на LazyVim: [[neovim-i-lazyvim-s-nulya|установка Neovim и LazyVim]].

## Buffer ≠ window

Это разделение путает почти всех новичков:

- **Buffer** — представление содержимого открытого файла в памяти.
- **Window** — видимая область экрана, которая **показывает** какой-то buffer. Несколько окон могут показывать один и тот же buffer одновременно.

Открыть файл (`:e file.txt`) — создать buffer. Разделить экран — создать ещё одно окно для того же или другого buffer.

## Разделение экрана: `:split` и `:vsplit`

```
:split file2.txt
:vsplit file2.txt
```

`:split` делит окно по горизонтали (новое окно снизу), `:vsplit` — по вертикали (новое окно сбоку). Переключение между окнами — `Ctrl-w` + `hjkl`. Смысл не в красоте, а в том, чтобы видеть содержимое нескольких файлов одновременно — сравнивать код или держать связанные файлы в поле зрения без переключения контекста.

## Быстрое переключение буферов: `:b <имя>`

Открыто 10+ буферов — перебирать их по одному через `:bnext` медленно. Быстрее:

```
:b <часть_имени><Tab>
```

`:b` с частью имени файла и автодополнением по Tab находит нужный буфер за пару нажатий. Ещё быстрее — fuzzy-finder плагин (в LazyVim это Telescope/Snacks): вместо точного ввода имени — интерактивный live-поиск с нечётким совпадением и превью содержимого. Именно ради таких вещей стоит перейти с голого Vim на LazyVim — следующий туториал этим и занимается.

## Проверка себя

Откройте три разных файла как отдельные буферы (`:e file1`, `:e file2`, `:e file3`), разделите экран `:vsplit`, чтобы видеть два из них одновременно, затем переключитесь на третий буфер через `:b` с частичным именем и Tab-автодополнением, не набирая имя целиком.
